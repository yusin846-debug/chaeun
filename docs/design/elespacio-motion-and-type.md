# Elespacio 세부 모션·타이포 분석과 채운 적용안

2026-09-28. 공식 홈 https://www.elespacio.net/ 의 Chrome 렌더링, 공개 CSS, 스크롤별 computed style을 대조했다. 확인 범위는 홈과 모바일 메뉴다. 전 사이트의 모든 내부 페이지나 영상 편집 타임라인을 분석한 것은 아니다. 아래 원본 수치와 채운 제안 수치를 구분한다. 제품 코드는 변경하지 않았다.

## 타이포 관찰

- 실제 HTML 글꼴은 Bricolage Grotesque. 로고 자형이나 영상 속 모든 글꼴까지 같은 글꼴이라고 단정하지 않는다.
- 첫 소개 문장은 큰 300 굵기와 핵심 구절의 굵은 표현을 병치한다.
- 1440px 화면의 h1: 72px / 행간 1.04 / 자간 -.03em. 390px 화면에서는 약 42px.
- 카드 제목: 데스크톱 약44px / 700 / 행간1.04 / 자간-.02em; 모바일 약28.5px.
- 크기, 굵기, 좁은 행간과 큰 주변 여백으로 편집적 위계를 만든다. 모든 글자를 굵게 키우거나 자간을 넓히는 방식이 아니다.
- 한글에 영어의 1.04 행간과 -.03em 자간을 그대로 복사하지 않는다. 받침과 큰 음절 덩어리의 밀도를 실제 크기에서 점검한다.

## 채운 모션 제안 — 아직 최종 승인값 아님

### 1. 진입

사진을 즉시 보여주고 제목은 의미 단위의 줄별로 12~18px 올라와 멈춘다. 550~700ms, 줄 간격은 70~100ms. 글자 한 자씩 타이핑하지 않는다. CTA는 처음부터 사용할 수 있고 애니메이션이 클릭을 지연하지 않는다.

### 2. 빛

데스크톱은 넓게 번지는 빛이 포인터를 부드럽게 따라온다. 제안 응답감 120~180ms. 모바일은 사진이 보이는 구간의 스크롤 진행률과 빛의 y 위치를 연결한다. 기본 방 밝기를 유지하며 제목과 버튼에는 효과를 적용하지 않는다. 사진의 자동 줌과 커서 흔들림을 동시에 추가하지 않는다.

### 3. CTA

Elespacio의 배경 형태 변화와 화살표 순환 방식을 채택한다. 배경 300~400ms, 화살표 450~550ms를 시안에서 비교한다. 긴 한글 버튼 문장은 찌그러뜨리지 않고 위치를 고정한다. 탭은 작은 눌림 후 즉시 생년일시 입력으로 이동한다.

### 4. 소재 단어와 사진

단어 밑줄 350~450ms, 디테일 사진은 opacity와 scale .96→1로 250~350ms 제안. 원본의 .8→1보다 움직임을 줄여 실제 소품 사진이 가볍게 튀어나오는 느낌을 피한다. 모바일은 작은 기본 사진 또는 탭 선택 구조로 호버 의존을 없앤다.

### 5. 카드 스택

색 / 소재 / 공간의 3개 사진 카드로 구성한다. 뒤 카드가 1→.95 정도 작아지고 윗부분이 남도록 제안한다. 스크롤 정지 시 애니메이션도 정지하며 역스크롤도 같은 경로를 따른다. 짧은 본문이 가려지기 전에 충분히 읽을 영역을 확보한다. 모바일은 촘촘하게 겹치지 않는다.

### 6. 메뉴와 갤러리

메뉴의 약한 탄성과 작은 기울기는 가져올 수 있다. 펫이나 히어로 방에는 적용하지 않는다. 모바일 메뉴 열림은 작은 엇박으로 항목이 나타나는 300~400ms 범위로 검토한다. 갤러리의 커서 화살표는 채택 가능하나 모바일에서는 명시적 이전/다음 버튼과 스와이프를 제공한다.

### 7. 공통 원칙

사진·빛은 부드럽게, 탐색·버튼은 빠르고 탄성 있게, 문장은 짧게 등장한 뒤 안정적으로 읽히게 한다. 한 화면의 시선을 끄는 주요 움직임은 하나로 제한한다. 모션 줄이기에서는 이동·축소를 생략하고 필요한 상태와 이미지를 그대로 제공한다.

## 채운 타이포 제안

- 워드마크: 모던한 산세리프 CHAEUN. 벌어진 얇은 대문자보다 압축감과 무게가 있는 자형·자간을 시안에서 비교한다. 글꼴 그대로 입력한 형태와 미세 조정한 형태를 구분해 제시한다.
- 한글: 현재 프로젝트의 Pretendard를 출발점으로 400~500 본문과 650~750 핵심 구절의 대비를 검토한다. 글꼴 이름만으로 독창성을 해결하려 하지 않는다.
- 히어로: 데스크톱 76~104px, 모바일 38~46px를 출발점으로 실제 문장 폭에 맞춘다. 행간1.12~1.18, 자간-.02em 안팎에서 비교한다. 확정 수치가 아니다.
- 문장 전체를 같은 굵기로 만들지 않는다. ‘당신의 사주,’는 중간 굵기, ‘더 좋게 흐를 수 있게.’는 강한 굵기로 대비하는 안을 우선 만든다.
- 모바일 줄바꿈은 의미 단위: ‘당신의 사주,’ / ‘더 좋게’ / ‘흐를 수 있게.’. 사진·CTA와 함께 검토하고 마지막 음절이 홀로 남지 않게 한다.
- 본문은16~18px, 행간1.55~1.7 범위. CTA는16px 안팎 중간~굵은 글자, 자연스러운 자간.
- 표제만 크고 본문은 과도하게 작아지는 구도를 피한다. 제목의 안정적인 가독성과 사진의 소품 식별을 함께 검수한다.

## 다음 목업의 필수 상태

정지 기본 상태 / 빛이 이동한 상태 / 소재 호버 상태 / 카드가 겹친 상태 / 모바일 세로 흐름. 별도로 워드마크와 한글 제목의 실제 크기 비교를 포함한다. 한 장짜리 목업으로 동작이 검증됐다고 판단하지 않는다.

# 랜딩 디자인 검토 — 2026-09-28

## 검토 기준

독창적이고 모던한 이미지 중심 브랜드. 한국 20~30대 여성이 작은 집에서도 공감하고 소품을 갖고 싶어 하는 실내 장면. 사주에서 시작해 풍수와 개인화 제안으로 이어지는 채팅 서비스. 상담 펫이 직접 화자다.

## 코드에서 확인한 충돌

- 실제 홈은 components/home/HomePage.tsx다. 히어로에는 자연 아이콘 궤도, 세 개의 분류 배지, 중앙 제목이 있고 방 사진은 없다.
- 첫 CTA는 #collection으로 스크롤한다. 사용자가 요청한 생년일시 입력으로 바로 연결되지 않는다.
- 본문은 그림 한 점, 풍경 만들기, 작품을 반복해 서비스 범위를 액자·아트 판매로 좁힌다.
- 자연 아이콘, 명조 제목, 종이 질감, 유기적인 배지 등 여러 표현이 동시에 등장한다. 브랜드를 대표할 하나의 시각 언어를 선정해야 한다.
- 사진은 긴 설명 뒤 등장한다. 첫 화면에서 인테리어 브랜드의 감각을 사진으로 증명하지 못한다.
- 컬렉션은 2.2초 간격으로 자동 이동한다. 사진 속 소재와 소품을 감상할 여유가 줄어들 가능성이 있다. 실제 이탈률은 측정 전이다.

## 제안 — 미확정

- 방 사진을 첫 화면의 주인공으로 배치하고, 선명한 워드마크와 타이포, 최소한의 오행 기호로 채운의 개성을 만든다.
- 원룸 규모가 느껴지는 구도, 조명·패브릭·의자·작은 오브제의 촉감을 살린다.
- 첫 CTA는 ‘내 기운의 흐름 알아보기’. 생년일시 입력으로 직접 연결한다.
- 흐름은 매력적인 방 → 나와 연결되는 이유 → 상담과 개인화 결과 → 시작하기로 압축한다.
- 랜딩의 움직임은 사진 속 빛과 소재를 발견하는 경험에 집중한다. 캐릭터의 반응은 상담 화면에서만 사용한다.

## 확정된 방향

- Co–Star의 참조점은 점성술을 모던하게 풀어낸 브랜드 이미지와 스크롤·호버 인터랙션이다. 도발적인 말투나 흑백 스타일의 복제는 확정된 요구가 아니다.
- 펫은 랜딩에 등장하지 않고 상담 시작 후 등장한다.

## 확정된 히어로 인터랙션

- 밝은 방의 기본 분위기를 유지한다. 빛이 닿는 소재의 질감과 색감이 더 아름답게 드러나는 방향을 사용자가 선택했다.
- 데스크톱: 마우스 위치를 따라 넓고 부드러운 빛이 이동한다.
- 모바일: 호버 대신 스크롤 진행에 따라 명암이 사진 위에서 아래로 이동한다. 터치 추적 방식 제안은 이 결정으로 대체한다.

### 구현 시 제안하는 세부 기준

- 사진이 보이는 구간에 맞춰 빛의 이동 범위를 정한다. 실제 가시 구간에서 시작과 끝을 확인한다.
- 역방향 스크롤에서는 빛도 같은 경로를 되짚는다. 사용자의 기본 스크롤을 가로채지 않는다.
- 방 전체와 소품이 평소에도 식별될 정도의 밝기를 유지한다. 검은 손전등 마스크처럼 처리하지 않는다.
- 명암 효과는 사진에만 적용한다. 제목·워드마크·CTA의 명암과 가독성은 일정하게 유지한다.
- 모션 줄이기 설정에서는 정적인 조명 상태로 보여준다.
- 사진 기반 명암 효과이며 실시간 3D 그림자나 반사 시뮬레이션으로 표현하지 않는다.

새 디자인 구현은 위 방향을 함께 정리한 뒤 진행한다. 확인한 코드 동작과 시각적 평가, 전환율에 대한 가설을 구분한다.

## 이미지 검토

추천 방과 액자/디지털 아트가 상품 디테일보다 먼저 크게 등장한다. 밝은 사진 위에 주요 카피가 겹치지 않고 주요 CTA는 기존 celadon을 사용한다. 반려 캐릭터나 앱 설치 버튼은 없다.

생성 이미지의 작은 글씨는 최종 조판이 아니다. 오행 원형의 목·화·토·금·수 표기가 작고 흐리므로 실제 조판에서 명확하게 표시해야 한다. 생성기가 추가한 오행별 성향 단어는 확정 콘텐츠가 아니다. 하단 자동 생성 연도와 추가 영문 문구는 최종 카피에서 제거한다.

전체 페이지 이미지에서는 왼쪽 목차가 첫 화면에 한 번 보인다. 웹 구현에서는 각 구간에 충분한 왼쪽 여백을 확보하여 고정 목차가 본문을 가리지 않도록 한다. 활성 구간과 클릭 이동을 연결한다. 기존 카드→도형 미디어→영상의 히어로 동작은 별도 시퀀스 설계를 유지하며 이 이미지 한 장으로 구현을 대체하지 않는다.

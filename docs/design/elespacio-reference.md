# Elespacio 레퍼런스 검토

2026-09-28. https://www.elespacio.net/ 를 Chrome에서 1440×1000, 390×844로 직접 열어 스크롤과 호버를 확인했다. 애플리케이션 구현은 변경하지 않았다.

## 직접 확인한 표현

- 짙은 배경, 굵고 큰 산세리프 워드마크, 오른쪽 위의 선명한 핑크 CTA. 첫 화면의 영상은 한쪽으로 치우쳐 있고 여백이 크다.
- 영상 안에서 문장·이미지·색면이 바뀐다. 정적인 히어로 배너가 아니다.
- 본문에서도 큰 글자와 굵기 차이로 위계를 만든다.
- 왼쪽의 말 머리 인물 영상과 타원형 제목이 머무는 동안 오른쪽 색면 카드들이 스크롤에 따라 쌓인다.
- 왼쪽 아래 메뉴는 서로 다른 색과 형태의 탭으로 쌓여 있다.
- 파트너 이름 Nespresso에 호버하면 밑줄과 별도의 로고 이미지가 나타난다. 텍스트가 시각 자료로 이어지는 상호작용이다.
- 상단 CTA는 호버 전후 둥근 정도가 바뀐다.
- 모바일에서는 영상→큰 소개 문장→인물과 카드의 세로 흐름으로 재구성되며, 하단 중앙의 원형 메뉴가 보인다.

## 이전 채운 목업의 실패

- 평범한 좌측 카피·우측 사진 분할로 멈춰 있어 화면 자체에 기억할 만한 구성이 없었다.
- 크림·버건디 색상과 예쁜 사진만으로 독창성이 확보됐다고 과대평가했다.
- 빛 인터랙션이 단순한 따뜻한 사진 조명으로만 표현돼 동작의 차이를 검토할 수 없었다.
- 데스크톱과 모바일의 축소판 한 장만 제시해 스크롤 경험을 설계하지 못했다.

## 채운으로 옮길 원칙 — 다음 목업 제안

- 큰 타이포와 이미지의 크기·겹침·여백을 통해 선명한 브랜드 인상을 만든다.
- 작은 방의 현실성과 소품의 매력은 유지하되, 사진을 일반 쇼핑몰 배너처럼 사용하지 않는다.
- 같은 방에서 빛의 위치가 바뀌고 소재가 드러나는 연속 장면을 설계한다.
- 소품이나 소재 이름을 가리키면 해당 디테일이 드러나는 방식으로 콘텐츠와 인터랙션을 연결한다.
- 원본의 말 캐릭터·무지개 메뉴·색상 배열을 그대로 가져오지 않는다. 채운의 펫은 상담 이후에만 등장한다.
- 밝은 방, 데스크톱 마우스 조명, 모바일 위→아래 스크롤 조명은 기존 확정 사항으로 유지한다.
- 다음 목업은 첫 화면 / 빛이 이동한 중간 화면 / 다음 섹션으로 이어지는 화면의 3개 장면을 만들어 연속성을 평가한다.

디자인 승인 전 제품 코드를 변경하지 않는다. 다음 목업 제안은 아직 사용자 승인된 최종 시안이 아니다.


## 상세 인터랙션 감사 — 두 번째 확인

직접 조작한 범위: 홈의 여러 스크롤 위치, 상단 CTA와 메뉴 호버, 파트너 이름 호버, 모바일 메뉴 열기/닫기, 모바일 카드 중첩. DOM의 실제 위치 속성도 확인했다.

### 1. 히어로: 시간 기반 영상

홈의 히어로에는 무음·인라인·배경 재생 옵션이 있는 Vimeo 영상이 포함돼 있다. 이미지와 타이포가 바뀌는 모든 장면을 스크롤 애니메이션으로 해석하면 안 된다. 채운의 히어로 조명은 사용자 입력에 반응해야 하므로, 사진에 빛을 겹치는 별도의 설계가 필요하다.

### 2. 스크롤 카드 스택

데스크톱에서 왼쪽 영상 영역은 sticky로 유지되며, 오른쪽 4개 카드는 상단 기준 112/130/148/166px에 차례로 머문다(1440×1000 관찰값). 앞 카드의 윗부분이 뒤 카드 위로 남아 깊이와 순서를 보여준다. 모바일에서도 카드가 겹친다. 숫자는 원본 관찰값이며 채운의 적용값이 아니다.

제안: 채운에서는 ‘기운이 색으로 / 소재로 / 공간으로 이어지는 방법’ 세 장으로 압축한다. 왼쪽에는 같은 방 또는 같은 소품을 유지하고 오른쪽에는 관련 디테일과 짧은 해석이 쌓인다. 상담 전 개인화 결과라고 주장하지 않는다.

### 3. 텍스트 호버 이미지

파트너 이름을 가리키면 밑줄과 대응하는 로고 이미지가 나타난다. 텍스트와 이미지가 분리된 목록이 아니라 함께 반응한다.

제안: ‘나무, 금속, 빛, 패브릭’ 같은 큰 소재·감각 단어에 해당 사진이 반응한다. 모바일은 탭으로 바꾸며, 최초 사진 하나를 기본 표시해 발견 가능성을 확보한다.

### 4. 메뉴와 CTA

데스크톱은 왼쪽 아래에 색·모양이 다른 메뉴 탭이 유지된다. 상단 CTA는 둥근 형태가 호버에서 더 각진 형태로 바뀐다. 모바일의 하단 원형 메뉴 버튼은 클릭 시 중앙에 탭 목록을 펼치고 배경을 어둡게 하며, 다시 클릭 시 닫힌다(aria-expanded true/false 확인).

제안: 채운의 정보 구조에 맞춰 메뉴를 브랜드/공간/소품 정도로 줄인다. 여섯 고민 선택지는 상담에 유지한다. CTA는 ‘내 기운의 흐름 알아보기’ 하나로 통일한다. 상단 CTA와 하단 메뉴가 서로 겹치지 않도록 모바일 위치를 별도로 설계한다.

### 5. 사진 편집

하단 아티클 영역은 동일 크기 카드의 반복이 아니라 큰 사진 한 장과 작은 사진들의 비대칭 구성이다. 사진 비율과 크기 차이로 리듬을 만든다.

제안: 방 전체→소품 단독→재질의 접사 순서로 거리감을 바꾼다. 항상 방 전체 사진만 반복하지 않는다.

## 사진 제작 및 검수 계획

| 에셋 | 역할 | 통과 기준 |
|---|---|---|
| 원룸 메인 컷 | 첫 화면의 선망과 공감 | 작은 주거 규모, 현실적인 동선, 소품이 배경에 묻히지 않음 |
| 메인 컷의 빛 위/중간/아래 상태 | 스크롤 연속성 검토 | 가구 위치·형태·카메라 동일, 빛만 변화, 기본 밝기 유지 |
| 조명 디테일 | 유리·금속·빛의 매력 | 메인과 동일 제품 형태, 광원·반사 일관성 |
| 의자 또는 테이블 디테일 | 나무·금속의 대비 | 다리·접합부·원근 오류 없음, 동일 재질 |
| 패브릭 디테일 | 촉감과 생활감 | 무늬·색·직조가 메인 컷과 연결, 과도한 플라스틱 광택 없음 |
| 모바일 전용 구도 | 세로 화면의 완성도 | 핵심 소품과 공간 규모가 동시에 보임, 사진의 무의미한 중앙 자르기 금지 |

원본 사진을 먼저 확정하고 같은 사진의 편집·크롭과 참조 기반 파생컷으로 확장한다. 광각 왜곡, 가구 접합, 창문 구조, 그림자 방향, 물체 중복, 가짜 텍스트, 재질 차이, 모바일 잘림을 하나씩 점검한다. 구조적으로 어색한 이미지는 예쁘더라도 채택하지 않는다.

## 제안하는 다음 디자인 산출물

1. 텍스트 없는 방 메인 컷과 소품 디테일 사진을 먼저 검수한다.
2. 데스크톱 히어로/빛 이동/카드 중첩의 세 장면을 만든다.
3. 모바일 히어로/중간 조명/카드 중첩을 별도 구성한다.
4. 각 장면에 trigger→변화→끝 상태를 기록한다. 정지 이미지가 작동하는 인터랙션이라는 인상을 주지 않는다.
5. 전체 디자인을 확인한 뒤 실제 웹 구현에 들어간다.

## 추가 검증: 가로 카드 탐색

슬라이더 오른쪽 영역에서 마우스를 움직이면 원형 화살표가 이동했다(관찰된 transform: translate3d(24px, -36.9375px, 0px)). 작은 버튼 자체가 아니라 넓은 좌우 영역이 입력을 받는다. 해당 영역의 클릭 전후 카드 화면도 캡처했다. 채운에서는 결과 이미지 갤러리에서 사용할 수 있으나, 히어로 조명과 같은 화면에서 중복 사용하지 않는 편이 좋다.

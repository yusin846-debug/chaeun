# 히어로 수정안: 설명 카드 → 도형 미디어 → 공간 영상

## 사용자 피드백 — 2026-09-28

1. 밝은 사진 위의 흰 제목은 가독성 문제가 있다.
2. 태그와 CTA는 기존 채운 브랜드 색을 사용한다.
3. Elespacio의 설명 카드 두 장, 도형 안 미디어, 이후 영상으로 이어지는 구성도 고려한다. 이 구성을 위해 호버 인터랙션을 없애도 된다.

## 이번 목업의 반영 사항

- 제목과 설명은 항상 단색 면 위에 놓고 사진과 겹치지 않는다.
- 배경 #252525, 본문 #f6f4ee. CTA는 청자색 #87a99a와 먹색 글자. 태그는 솔잎색 #315848 / 테라코타 #b55a43 / 금색 #b89b62를 사용한다. 라일락은 제거한다.
- 네 장면: ‘사주로 지금의 나를 읽고.’ 카드 → ‘풍수로 필요한 기운을 채워요.’ 카드 → 도형 속 조명·의자 디테일 → 방 전체 영상.
- 고정 CTA는 어떤 장면에서도 생년일시 입력으로 진입한다. 인트로가 끝날 때까지 기다리게 하지 않는다.
- 과거 커서 조명은 필수 요구에서 재검토 대상으로 옮긴다. 이번 후보는 호버 없이 이해되는 순차 연출이다. 모바일도 같은 내용이 전달된다.

## 제작 제안 — 확정 전

처음 두 문장을 짧게 보여주고 도형 속 미디어로 전환한 뒤 4~6초 공간 영상에 도달한다. 장면별 정확한 시간은 읽기 테스트 후 확정한다. 긴 인트로를 계속 반복하지 않도록 첫 설명은 한 번, 이후 공간 장면은 정지 또는 짧은 자연 루프로 제안한다. 영상은 무음이며 화면 밖에서 멈춘다. 재생 불가/모션 줄이기 상태에서도 설명과 결과 사진이 보인다.

실제 동영상이나 모션 구현이 아닌 네 프레임 이미지 목업으로 먼저 검토한다. 디자인 승인 전 제품 코드는 바꾸지 않는다.

## 대비 검토

계산상 먹색/청자색 5.96:1, 종이색/솔잎색 7.29:1, 먹색/금색 5.77:1. 종이색/테라코타는 4.24:1이므로 작은 일반 본문 조합으로 사용하지 않고 큰 굵은 태그/제목으로 제한한다(실제 웹에서는 최소 20px 굵은 태그 기준으로 재검증). 생성 목업의 색과 글꼴 크기는 정확한 CSS 값이 아니므로 접근성 통과를 의미하지 않는다.

# 랜딩 세 번째 수정

사용자 요청: 이미지 겹침 제거, 연애 이미지 교체, PNG 로고, 카드 안 직접 CTA, 레퍼런스처럼 독창적인 오른쪽 애니메이션.

- 여섯 이미지를 겹쳐 opacity로 전환하던 히어로를 제거했다. 한 번에 한 개의 네이티브 SVG/CSS 조형 장면만 렌더링한다.
- 왼쪽 카드와 오른쪽 장면은 별도의 minmax(0,1fr) 그리드 영역과 28px 간격을 갖는다. 각 영역의 overflow를 제한한다.
- 장면: 혼자인 밤(달과 궤도), 연애(가까워지는 두 하트), 일(화살표와 계단), 돈(차곡차곡 쌓이는 원반), 쉼(돌과 파문), 취향(모양 모빌).
- 원본 레퍼런스의 말 캐릭터 영상은 복제하지 않았다. 사용자가 제안한 독립 애니메이션 영역과 카드 안 CTA 구조를 적용했다.
- 카드 안 CTA는 기존 startReading 액션을 사용하여 출생 입력으로 연결한다. 스크롤 이야기 순서를 유지하며 CTA DOM은 전환 중에도 유지한다.
- 애니메이션 정지/재생 버튼, prefers-reduced-motion 지원.
- 삼성 로고 원본 SVG를 PNG로 래스터화했다. SK/현대와 함께 사례 카드의 로고는 모두 PNG를 사용한다.
- 인테리어 사진과 소품은 아래의 해당 섹션에 유지한다.

브라우저 도구의 보안 정책 확인 실패로 실제 시각 검증은 여전히 미완료다. 이미지 겹침을 유발하던 구조는 소스에서 제거했고 타입·lint·빌드 및 기존 회귀 테스트로 검증한다.

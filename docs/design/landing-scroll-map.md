# 랜딩 스크롤 구성과 목차

## 사용자 확정 요구

왼쪽 태그는 아래 스크롤 구간과 연결되는 목차다. 장식이나 상품 필터로 동작하지 않는다.

## 제안하는 구간

| 목차 | 화면 | 전달하는 내용 |
|---|---|---|
| 채운 | 설명 카드 두 장 → 도형 미디어 → 방 영상의 히어로 | 서비스의 첫 인상 |
| 공간 | 공감하는 질문 → 추천 방 사진·짧은 영상 카드 | 나를 이해하는 상담과 갖고 싶은 공간 |
| 맞춤 아트 | 액자 속 이미지와 같은 작품의 디지털 이미지 | 필요한 기운을 색과 형태로 담는 개인화 결과 |
| 사주·풍수 | 생년월일시·오행 개념과 빛·소재·공간의 연결 | 해석이 공간으로 이어지는 이유 |
| 사례 | 출처가 있는 현대 건축 사례를 큰 질문·미디어·짧은 설명으로 제시 | 흥미와 사실에 기반한 신뢰 |
| 소품 | 조명·소재·패브릭 상세컷과 상담 시작 | 마음에 든 공간 분위기를 생활에 옮기는 후속 추천 |

스크롤로 서비스와 결과를 이해하는 랜딩이다. 개인화 결과는 실제 입력과 상담 이후 제공한다. 랜딩 사진을 방문자의 분석 결과처럼 표현하지 않는다. 고민 선택은 상담 안에서 유지한다.

## 목차 동작

- 데스크톱에서는 왼쪽 목차가 화면에 고정된다.
- 수동 스크롤 시 현재 구간의 태그가 강조된다. 강조는 색만이 아니라 윤곽·화살표·크기 차이로 표시한다.
- 태그 클릭 시 해당 구간의 제목으로 이동한다. 고정 헤더에 제목이 가리지 않게 여백을 둔다.
- 클릭 후 스크롤 중 지나가는 구간마다 강조가 빠르게 깜빡이지 않게 한다. 사용자가 스크롤을 직접 조작하면 이동을 중단할 수 있다.
- 마지막 구간에 도달하면 소품이 활성화된다. 이동은 브라우저 기본 스크롤 흐름을 보존한다.
- 모바일 제안: 세로 목차 대신 헤더 아래의 얇은 가로 목차로 같은 구간을 제공한다. 사진 위에 겹쳐 놓지 않는다.
- 키보드로 각 항목을 사용할 수 있고 현재 위치를 접근성 속성으로 전달한다. 모션 줄이기는 즉시 이동한다.

## 영상 및 CTA

최신 목업의 CTA는 **내 사주에 어울리는 공간 보기**. 보조 문구는 **생년월일시로 시작해요**. 히어로 제목은 **나를 읽고, 나를 닮은 공간을 만나다.**

공감 → 추천 방 → 맞춤 액자 아트를 먼저 보여준다. 소품 구매를 첫 약속으로 제시하지 않는다. 소품 섹션 카피는 **마음에 든 이 분위기, 내 공간에도.** 랜딩에는 상담 후의 공유·저장·990원 구매 기능을 끌어오지 않는다.

목차는 페이지 구간과 연결되고, 히어로 내부 카드 두 장/미디어 장면은 별도 재생 순서다. 영상 한 컷마다 페이지 목차를 바꾸지 않는다. 상단 상담 CTA는 항상 생년일시 입력으로 진입한다. 소품 구간의 마지막 상담 CTA도 같은 목적지다.

## 상태

연속 이미지 목업으로 검토 중. 목차 연결은 사용자 요구로 확정됐으나 구간 이름·상세 레이아웃은 아직 최종 디자인 승인이 아니다. 제품 코드는 변경하지 않았다.


## 설명 및 신뢰 콘텐츠 보강

사용자가 사주·오행·풍수 설명과 실제 사례에 기반한 신뢰 콘텐츠를 요청했다. 사전식 긴 설명을 피하고 각 구간은 한 질문·한 핵심 시각 자료·짧은 해설로 구성한다.

- 사주: 생년·월·일·시 네 기둥에서 해석한다는 개념. 자료: https://encykorea.aks.ac.kr/Article/E0025957
- 오행: 목·화·토·금·수를 시각 언어로 설명한다. 다섯 개를 똑같이 맞추는 단순 수량 게임으로 설명하지 않는다. 랜딩에 방문자의 가짜 수치를 표시하지 않는다.
- 풍수: 공간을 해석하는 전통적 관점과 채운의 색·소재·공간 제안을 연결한다.
- 실제 사례: HSBC 공식 2026-06-17 인터뷰에서 노먼 포스터가 풍수 전문가와 상담했으며 에스컬레이터 축 방향에 그 조언이 반영됐다고 설명한다. https://www.hsbc.com/news-and-views/news/hsbc-news-archive/back-to-the-future
- 사례 제목 제안: ‘은행의 에스컬레이터에도 풍수가?’ 출처와 원문 읽기를 카드 내부에 제공한다. 이 사례로 사업 성과나 풍수 효능이 입증됐다고 주장하지 않는다.
- 실제 건축물의 사진은 검증한 자료를 사용한다. 생성한 가상의 건축 사진을 실제 사례 증거로 쓰지 않는다. 목업은 ‘개념 도해’로 표시한 선형 도해와 공식 출처 텍스트를 사용한다.
- IKEA 원룸 가이드는 생활 공간의 조명·배치 참고이며 풍수 도입 사례로 분류하지 않는다. https://www.ikea.com/kr/ko/campaigns/studio_living_solution-pube3601b10/
- 사용자 요청으로 랜딩의 사례는 삼성·현대·SK로 교체한다. HSBC는 배경 조사로만 남긴다. 아래 검증한 범위의 카피를 사용한다.
- 공통 표시는 출처가 있는 사실과 채운의 해석을 구분한다. 사례는 채운 고객사나 협력 관계처럼 보이게 하지 않는다.

## 국내 기업 사례 카드 (2026-09-28)

섹션 제목: **삼성, 현대, SK. 그 공간에 얽힌 풍수 이야기.**

세 장의 큰 편집형 카드를 스크롤에 따라 겹쳐 전환한다. 왼쪽 목차는 세 카드 전체에서 ‘사례’를 유지한다. 기업 로고 나열 대신 건물명·후킹 질문·짧은 본문·출처 링크를 사용한다.

1. **삼성 — 삼성 서초사옥은 풍수로 어떻게 읽힐까요?**
   - 본문: 매경이코노미는 서초사옥 주변 지형과 물의 흐름을 풍수 전문가의 해석으로 소개했습니다.
   - 근거 유형: 언론 보도 속 전문가 해석. 삼성의 공식 설계 의도라고 표현하지 않는다.
   - 출처: 매경이코노미, 2011-12-25, https://www.mk.co.kr/news/business/5064418
2. **현대 — 현대차 양재사옥, 풍수 연구의 대상이 되다.**
   - 본문: 2025년 연구는 사옥 주변의 산과 하천, 건물 형태와 공간 구성을 풍수의 관점으로 분석했습니다.
   - 근거 유형: 외부 연구. 현대차가 풍수를 이유로 입지를 선정했다는 공식 확인과 구분한다.
   - 출처: 함명진·박정해, ‘현대차그룹 양재동 사옥 입지의 특징과 해석’, 산업진흥연구 10(3), 377–391, https://doi.org/10.21186/IPR.2025.10.3.377
3. **SK — SK 사옥에는 왜 거북이의 형상이 있을까요?**
   - 본문: 서린사옥의 기둥과 출입구에 담긴 거북 형상은 불의 기운을 보완하려는 풍수 이야기로 보도됐습니다.
   - 근거 유형: 언론 보도. 거북 형상 디테일이 강하므로 첫 카드로 배치해도 좋다.
   - 출처: 조선일보, 2007-09-21, https://biz.chosun.com/site/data/html_dir/2007/09/21/2007092101197.html ; 문양 확인 보강: 위 매경이코노미 기사.

다음 공간 구간 연결 문구: **큰 사옥의 이야기에서, 나를 위한 작은 공간으로.**

기업의 성공이나 개인의 운 개선을 사례로 입증했다고 표현하지 않는다. 기존 HSBC 이미지 목업은 이 변경을 반영하지 않은 이전 버전이다. 국내 사례용 실제 건물 사진 및 사용 권한은 아직 확보 전이며, 가상의 생성 건물을 실사 자료처럼 사용하지 않는다.

# Issue tracker: GitHub

명세와 승인된 작업은 https://github.com/yusin846-debug/chaeun/issues 에서 관리한다. 인증된 GitHub 커넥터를 사용하며, gh가 설치 및 인증된 환경에서는 CLI를 사용할 수 있다. 저장소는 origin과 대조한다.

- 게시 전 기존 이슈를 조회해 중복을 피한다.
- 작업은 사용자에게 보이는 동작, 선행 작업, 수용 기준, 검증 기준을 포함한다.
- to-tickets 작업 분해는 사용자에게 제시하고 승인된 항목을 게시한다.
- 실제 준비된 작업에 ready-for-agent를 적용한다. 미정 결정이나 해결되지 않은 의존성이 있으면 준비 완료로 표시하지 않는다.
- 테스트와 리뷰 전 완료 처리하지 않는다.
- PRs as a request surface: no.

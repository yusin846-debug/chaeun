# 슈슈 개인화 상담 공동 편집

## 확정된 방향
- 승혜(돈) → 유민(커리어, 이사·자취는 본인이 원할 때만) → 윤지(연애) → 현우(커리어) 순으로 검토한다.
- 네 사례의 상담과 대시보드를 기존 흐름에서 검증한다. 외부에서 들은 배경을 상담자가 아는 사실처럼 주입하지 않는다.
- 슈슈는 상담 시작에 자기소개를 하고, 이름 또는 별명을 물어 콘텐츠에 활용한다.
- 호칭 답변과 주제 확인은 고민에 관한 실제 대화 5회에 포함하지 않는다.
- 출생 자료는 사용자가 제공한 이미지로 확인하되 이 설계 문서나 공개 테스트에 실명·생년일시를 복사하지 않는다.

## 현재 결정할 항목
- 자기소개는 사용자가 요청한 픽션 캐릭터 설정으로 다룬다. 실제 교수진 자문이나 자료 집대성 실적으로 표현하지 않는다.
- 승혜 시나리오는 돈 카드를 강조한다. 시나리오 연출과 실제 원국·현재 대운 기반 추천은 구분한다.
- 첫 질문 이후 어느 답변으로 진행할지는 사용자가 선택한다.

## 확정된 첫 돈 질문
“승혜야, 돈 이야기를 조금 해볼까? 지금 들어오는 돈을 잘 모으고 싶은 마음이 커, 아니면 앞으로 내가 뭘 해서 돈을 벌게 될지가 더 신경 쓰여?”

선택지:
- 돈을 벌 기회가 생겼으면 좋겠어
- 버는 만큼 잘 모으고 싶어
- 앞으로의 생활이 막막해
- 조금 다른 고민이야

상담자는 사용자가 직접 밝히지 않은 취업 상태를 아는 척하지 않는다. 외부에서 전달받은 시나리오 배경은 캐릭터의 지식으로 주입하지 않는다.

첫 선택지의 후속 질문 제안: “지금은 어떤 일을 해야 할지 찾는 중이야, 아니면 하고 싶은 일은 있는데 기회가 잘 안 잡히는 쪽이야?” 실제 선택 전에 응답이나 감정을 확정하지 않는다.

## 다음 단계
첫 인사와 호칭 → 돈 주제의 상황 선택 → 사용자 응답 → 계산된 원국과 대운에 연결한 다음 대사 → 중간 점검 → 공간 제안 순으로 편집한다. 첫 두 결정이 정해지면 승혜 사례의 다음 장면을 작성한다.

## 2026-09-30 구현·QC 반영
호칭 → 필수 주제 확인 → 실제 답변 5회 → 중간 점검 → 동네·방 입력 → 대시보드를 연결했다. 방 취향은 직접 선택을 우선한다. 네 참여자의 방 매칭 요청에 따라 알려진 이름·별명에는 합의한 공간 프리셋을 자동 추천하고 입력 화면에 추천 구성을 표시한다. 이름으로 사생활이나 사주를 추론하지 않으며 다른 별명에는 방 구조 기본값을 사용한다. 대시보드 첫 카드는 개인 사연을 직접 노출하지 않고 함께 살필 흐름과 기대하는 일상을 보여준다. 실제 API 및 화면 검증은 `../qa/personalized-flow-qc.md` 참조.

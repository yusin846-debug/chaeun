# 상담 에이전트 설계 인터뷰

2026-09-29. 사용자가 grill-with-docs로 실제 채팅 에이전트 구현을 요청했다.

## 기존 대화에서 확정된 제품 방향
- 상담 펫이 직접 말하는 화자다. 랜딩에서는 등장하지 않는다.
- 생년일시 입력 뒤 사주를 바탕으로 흥미로운 자기 해석을 먼저 전달한다.
- 이후 관심사를 넌지시 질문한다. 특정 주제 CTA 유입은 해당 관심사를 유지하며, 일반 진입을 연애로 고정하지 않는다.
- 연애·재물·쉼/건강·외로움·인테리어/취향 등 관심사 선택과 직접 입력을 제공한다. 현재 랜딩은 일/새로운 시작도 포함하는 여섯 주제다. 직접 입력은 별도 자유 입력 진입으로 보존한다.
- 대화 약 3~4회 왕복 후 사용자의 고민과 보완 방향을 눈에 들어오는 이야기·도표로 중간 정리한다. 새 고민을 말하면 기계적으로 단계를 강제하지 않는다.
- 다음 풍수 맥락 수집은 동네, 주변 산/물/도로/건물, 창과 뷰, 주거 형태를 복수 선택·직접 입력·건너뛰기로 진행한다.
- 결과는 개인화 공간 이미지와 동네 추천이 우선이다. 대시보드는 결과/공유 화면 가까이에 둔다.
- 보완 아트는 방 인테리어 이미지와 구분한다. 공유 특전 또는 990원 결제 후 제공하는 후속 단계다.
- 기운 보완을 단일 행동 코칭이나 소품 구매로 축소하지 않는다.

## 현재 확인한 구현 차이
- /create는 브라우저 메모리에 입력을 보관하는 시제품이다. 채팅 전송 및 모델 응답은 연결되지 않았다.
- lib/ohaengMock.ts의 생년일시 숫자합 계산은 실제 사주 계산이 아니다. 에이전트의 분석 근거로 사용하지 않는다.
- 실제 계산과 대화의 자유로운 표현을 구분해야 한다. 모델이 간지/오행 원자료를 지어내지 않도록 계산 결과를 별도 전달한다.

## 1차 질문 — 사용자 확정
1. 첫 완료 범위: 실제 사주 계산/첫 해석/여섯 관심사 및 직접 입력/자유 대화/중간 정리까지. 풍수 결과와 생성/결제는 후속 단계.
2. 출생 범위: 한국 출생만 우선 지원.
3. 펫 말투: 다정하고 재치 있는 반말. 짧은 2~3개 말풍선, 한 번에 질문 하나, 실제 사용자 답변을 반영.

## 2차 질문 — 사용자 확정
4. AI 제공자: OpenAI API로 시작. 키는 서버 설정에 보관하고 대화나 문서에 기록하지 않는다.
5. 대화 보존: 로그인 없이 이 브라우저에서 이어가기. 새로고침 후 복원하고 상담 지우기로 생년일시와 대화를 함께 삭제한다. 응답 생성에 필요한 정보의 AI 제공자 전달을 질문에서 안내했다.
6. 상담 펫 외형: 둥근 크림색 고양이가 직접 상담한다. 인사·생각 중·답변·공감 상태에 반응한다.

## 연동 현황 추가 확인
읽기 전용 조사 결과 현재 API 라우트, 모델 SDK, 인증/DB 및 서버 환경변수 참조가 확인되지 않았다. 실제 모델 연결과 키 설정부터 필요하다. 키 값은 문서나 대화에 기록하지 않는다.

## 이후 확정할 의존 결정
- 만세력 계산 공급원, 절기/입춘 기준, 자시 일자 경계, 출생 시간대와 시각 보정, 시간 모름/음력 윤달 처리 및 대조 사례.
- 대화 모델 제공자와 실제 호출 경로, 키 설정, 비용/출력 제한, 오류와 재시도.
- 사용자에게 기억되는 대화와 저장 범위, 수정/삭제/새 상담 정책.
- 상담 펫 외형/이름과 반응, 첫 응답·근거·질문·중간 정리의 대화 명세.
- 계산된 사실, 전통적 해석, 사용자가 직접 알려준 정보를 분리한다. 연구로 입증되지 않은 운세 결과를 과학적 사실로 표시하지 않는다.

사용자가 최종 설계에 “엉엉”으로 동의했다. 아래 구현 제안으로 진행한다. 구현 검증 상태는 별도 기록한다.

## 3차 질문 — 사용자 확정
7. 한국 기준으로 계산한다. 사용자는 자정/23시 관법을 별도로 지정하지 않았으므로 아래 자정 기준은 구현 제안이며 한국의 유일한 표준이라는 의미가 아니다.
8. 첫 버전부터 대운을 포함한다. 입력 단계에서 성별을 함께 묻는다.
9. 중간 정리 후에도 같은 채팅에서 대화를 이어간다.

## 최종 구현 제안 — 2026-09-29 사용자 승인
- 입력: 한국 출생, 양력/음력/윤달, 생년월일, 출생 시간 또는 시간 모름, 대운 계산용 성별(여성/남성, 기본 선택 없음).
- 계산 관법 제안: 입춘 시각으로 연주, 절입 시각으로 월주, 자정으로 일자 변경. 기록된 한국 법정시를 사용하고 해당 연도의 표준시·서머타임은 정규화한다. 출생지 경도/진태양시 보정은 첫 버전에 적용하지 않는다.
- 대운 순역 제안: 연간 음양과 입력 성별로 양남음녀 순행·음남양녀 역행. 순행은 다음 절입, 역행은 이전 절입까지의 간격을 3일=1년으로 환산한다. 엔진의 실제 지원/반올림 방식을 검증하고 계산 메타데이터에 보관한다.
- 시간 모름: 시주를 생성하지 않는다. 절입일의 연·월주와 대운 시작 시점처럼 시간에 따라 달라질 항목은 후보/범위로 처리하고 단일 확정값으로 말하지 않는다.
- 엔진 후보: MIT manseryeok v2. 배포/소스 일치 및 KASI 달력·절기 사례 검증 후 채택. 원자료는 서버에서 계산하고 모델이 생성하지 않는다.
- 첫 대화: 크림색 고양이가 일간·원국의 관계에서 특징을 짚고 사용자에게 맞는지 묻는다. 여섯 고민과 직접 입력을 유지하며 주제 CTA 유입 의도를 반영한다.
- 중간 정리: 약 3~4회 왕복 후 오행 도표와 원하는 것/이미 가진 강점/더 채울 기운을 채팅 내 카드로 제공. 입력창과 이어지는 대화를 유지한다. 단순 오행 개수 최솟값을 용신으로 단정하지 않는다.
- OpenAI 응답: 서버 경유, 모델 설정 교체 가능, 짧은 말풍선·질문·정리 카드 구조 검증. 오류 시 작성한 메시지를 보존하고 재시도 제공. 실제 연결 실패를 가짜 상담 응답으로 감추지 않는다.
- 저장: 이 브라우저에 상담을 복원 가능한 형태로 보관. 상담 삭제 시 출생 정보와 대화 삭제, 출생 정보 변경 시 기존 원국에 기반한 상담은 재시작 안내. API 응답의 별도 저장은 비활성화하되 제공자 보존 정책과 혼동하지 않는다.
- 구현 순서: 입력/실제 계산과 경계 검증 → 펫/첫 해석/주제 선택 → 실제 대화/복원/삭제 → 중간 정리 및 지속 대화 검증.
- 다음 단계: 풍수 맥락 수집, 개인화 방/동네 결과, 이미지 생성, 공유/결제.

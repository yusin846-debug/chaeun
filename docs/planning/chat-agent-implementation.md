# 채운 상담 에이전트 1차 구현

2026-09-29 사용자 승인 설계. `/create`에서 한국 출생 사주·대운 → 고양이의 첫 해석 → 고민 선택/직접 입력 → 자유 상담 → 중간 정리 후 계속 대화를 지원한다.

## 실행 설정
프로젝트 루트의 Git 제외 파일 `.env.local`에 직접 입력한다. 키는 대화·스크린샷·커밋에 넣지 않는다.

```
OPENAI_API_KEY=발급받은_키
OPENAI_MODEL=gpt-5.4-mini
```

키 발급: https://platform.openai.com/api-keys
키 입력 뒤 실행 중인 production 서버는 재시작해야 한다. 기본 모델은 설정으로 교체 가능하며 1회 응답 2,500 토큰·45초 제한, 자동 재시도 없음. Responses API의 `store:false`로 호출한다. 이는 제공자의 모든 로그 보존이 없다는 뜻은 아니다.

## 계산 기준
- 고정 엔진 `manseryeok@2.0.0` (MIT), npm 배포와 타입/계산 소스 확인. 자체 엔진의 정확도 인증으로 표현하지 않는다.
- 1920년부터 현재까지, 한국 음력·윤달 검증 후 양력 변환. 양력·미래 날짜와 시간도 서버 검증.
- IANA `Asia/Seoul`로 벽시계 시각을 왕복 검증한다. 과거 한국 표준시·DST를 UTC+9로 정규화하고 엔진에는 보정된 표준시를 전달한다. 경도·균시차 보정 없음.
- 입춘 연주, 절입 월주, 자정 일자 변경. 대운은 연간 음양·성별에 따라 양남음녀 순행 / 음남양녀 역행, 인접 절입 간격 3일=1년. 표의 대운수는 엔진의 연 단위 반올림이다.
- 시간 모름은 유효한 하루의 모든 분을 계산하고 시주를 제거한다. 절입일·DST의 가능한 원국을 중복 없이 제시하고 대운 시작을 범위로 반환한다. 임의의 정오 시주는 없다.
- 알려진 시간인데 DST 전환의 중복/없는 시각이면 기록 재확인 또는 시간 모름을 안내한다.
- 오행 도표는 천간·지지 본기 개수다. 강약/용신 점수 아님. 최소 개수를 용신으로 정하지 않는다.

## 상담과 저장
- 서버에서 계산을 다시 수행하므로 브라우저가 전달한 원국을 신뢰하지 않는다.
- 구조화 응답: 말풍선 1~3개, 질문 하나, 고양이 표정, 선택적 중간 정리.
- 첫 해석 뒤 여섯 고민과 직접 입력. CTA 주제를 첫 해석에 전달하고 사용자가 바꾸는 고민도 따른다.
- 네 번째 사용자 답변에 중간 정리. 이후 자유 대화와 후속 정리를 계속한다.
- 브라우저 저장 키 `chaeun.consultation.v1`. 출생 정보, 선택 주제, 대화 저장. 기기 간 동기화 없음. 삭제 확인 후 해당 키 삭제. 수정은 상담 초기화 안내 후 입력으로 돌아감.
- 전송 실패 시 사용자 메시지를 보존하고 중복 추가 없이 재시도. 새로고침 후 미완료 메시지는 이어서 연결하기 제공.
- 아주 긴 상담은 최초 해석과 최근 98개 메시지를 전달한다. 최근 창 이전 상세 발언을 모두 기억하는 영구 기억은 아니다.
- 동일 출처 POST, 서버 스키마/실제 본문 크기 제한, 프로세스당 30회/분과 동시 AI 호출 4개. 공개 다중 서버 배포 전에는 공유 요청 제한·예산 관리가 필요하다.

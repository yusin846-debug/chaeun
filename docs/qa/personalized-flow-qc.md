# 개인화 상담 흐름 QC

검증일: 2026-09-30

기존 생년정보 → 호칭 → 필수 주제 확인 → 실제 답변 5회 → 중간 점검 → 동네·방 입력 → 대시보드 흐름을 유지했다. 호칭과 주제 선택, 대사 페이지 넘기기는 답변 횟수에 포함하지 않는다.

## 실제 API 검증

사용자가 네 사례의 출생정보·이름·테스트 대화를 OpenAI에 전송하는 것을 명시적으로 승인한 뒤 실행했다. 원문과 생년정보는 공개 테스트나 이 문서에 포함하지 않았다.

| 사례 | 주제 | 방 콘셉트 | 결과 |
| --- | --- | --- | --- |
| A | 돈 | 작품 카드를 살린 개인 침실 | 5회 답변, 중간 점검, 대시보드 성공 |
| B | 커리어, 이후 이사 검토 | 원목·네이비 빈티지 개발 작업방 | 5회 답변, 중간 점검, 대시보드 성공 |
| C | 연애 | 밝은 원목·파스텔 공간 콘셉트 | 5회 답변, 중간 점검, 대시보드 성공 |
| D | 커리어 | 암막커튼·듀얼 모니터 게임방 | 5회 답변, 중간 점검, 대시보드 성공 |

B만 이사 의사를 명시하여 동네 후보가 나타났다. 기흥 출퇴근 맥락에서 무관한 해안 지역이 나오던 문제를 고쳐 수서·기흥 생활권을 비교할 후보로 재검증했다. 정확한 직장 주소와 교통 시간·주거비는 확인되지 않았으므로 최적 통근지로 단정하지 않는다. 현재 동네 궁합과 이사 후보의 근거를 섞지 않는다.

## 발견하고 수정한 문제

- 생시가 있는데 여섯 글자로 부르거나 일주를 일간으로 부르는 응답: 응답 검사와 1회 재생성.
- 설명과 질문에 같은 질문이 중복: 질문 필드로 일원화.
- 비슷한 감정 질문 반복: 후반 질문을 실행 조건 → 다른 활동에서의 강점 → 공간 단서로 전환.
- 마지막 방 이야기가 원래 상담 주제를 덮는 요약: 초기 답변과 선택 주제를 중간 점검의 중심에 유지.
- 요약의 보완 오행과 화면 구슬 불일치: 같은 보완 목록으로 정리.
- 대시보드에서 사적인 연애 사연 직접 노출: NOW/NEXT 카드는 부드러운 방향과 기대 일상으로 표현. 저장된 기존 결과에도 즉시 적용. 새 생성 설명도 사건 재인용 금지.
- 방 사진과 소품: 각 방 사진에서 뽑은 디테일을 사용하고 액자를 먼저 배치.
- 불확실한 실제 방 구조: 이미지는 취향·생활 조건을 참고한 콘셉트라고 표시.

## 화면 및 회귀 검사

- 브라우저에서 생년정보 입력·호칭·주제 확인·실제 첫 답변과 페이지 진행 확인.
- 글자가 나오는 동안 Enter 연타로 대사를 건너뛰지 않음, 질문이 끝나면 입력 가능.
- 네 실제 API 기록을 별도 개발 포트에 불러와 대시보드·이미지·소품·동네 조건 확인.
- 새로고침 후 상담과 대시보드 복원 확인.
- 좁은 화면의 한 열 카드와 하단 슈슈 도우미 확인. IAB 뷰포트 캡처에 비정상적인 빈 띠가 있어 모바일 시각 검증은 제한적이며 실제 기기 확인은 별도 필요.
- 자동 테스트 39개 통과, 수정 대상 ESLint 통과, production build 통과.
- 테스트 기록 가져오기 `/qc`는 개발 모드 전용이며 production에서 404.

## 범위

실제 모델 응답은 달라질 수 있다. 이번 검증은 4개 전체 API 시나리오와 화면/복원 검사이며 모든 가능한 자유 답변을 보장하지 않는다. 그림은 선택한 취향과 방 조건에 대응하는 준비된 콘셉트이며, 사람의 이름이나 생년일시를 보고 몰래 배경 정보를 끼워 넣지 않는다. 사주·오행 연결은 상징적 해석이며 사건의 원인·확정 시점·안전을 보장하지 않는다.

## 2026-09-30 자동 방 매칭 수정

기존 QC는 roomStyle을 직접 지정했기 때문에 자동 추천 경로의 누락을 발견하지 못했다. 자동 추천은 이름/별명의 사전 합의한 네 참여자 프리셋을 사용하고, 직접 선택은 항상 우선한다. 서버가 해석한 입력을 응답하고 그대로 저장하므로 이미지·소품 목록·설명 생성에 동일한 방이 쓰인다. 출생정보나 성별로 취향을 단정하지 않는다.

- 승혜/진승혜: collector-bedroom-v1
- 유민/이유민: yumin-vintage-developer-v2
- 윤지/강윤지: yunji-pastel-loft-v1
- 현우/김현우: hyunwoo-gaming-room-v1

네 이미지 원본을 직접 확인했다. 자동 선택 × 이름/성명 × 네 구조, 직접 취향 우선, 저장 복원, 모르는 별명의 기본값, 이전 결과 재생성 판별을 테스트했다. 전체 42개 테스트, TypeScript, 변경 파일 ESLint 통과. 기존 잘못된 결과는 이미지와 설명을 임의로 섞지 않고 기존 대화를 유지한 채 공간 추천 재생성을 안내한다.
